# Superseded ExecPlans

Plans that were authored but replaced before execution. They are kept
intact so the Decision Logs, design history, and trade-off analyses
that informed the pivot remain reachable. Each file's top block names
the plan that supersedes it and summarises why.

Different from `completed/`: the work in `completed/` shipped; the
work in `superseded/` did not — a later design iteration replaced it.
A fresh contributor should read the active plan first; reach for the
superseded one only when archaeology helps (recovering rationale,
checking a rejected alternative, etc.).
