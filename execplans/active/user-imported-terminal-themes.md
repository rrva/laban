# User-Imported Terminal Themes

This ExecPlan is maintained in accordance with `PLANS.md`.

## Purpose / Big Picture

Users can now import their own terminal color themes into Laban from a JSON theme file. After importing, the theme appears in the View → Theme menu and in Settings → Appearance alongside bundled themes. Imported themes persist across launches in a private `~/Library/Application Support/Laban/themes/` directory and can be removed from Settings.

## Decision Log

- Decision: Store imported themes as individual JSON files inside `~/Library/Application Support/Laban/themes/` and derive the theme list by scanning that directory.
  Rationale: The directory becomes the source of truth, so there is no separate manifest to drift out of sync with files. Crash-left staging files are cleaned on store init and by `cleanupOrphans(keeping:)`.
- Decision: Reject imported theme names that collide with bundled theme names or with already-imported themes.
  Rationale: The rest of the app persists theme selection by name; unique names keep persistence unambiguous.
- Decision: Keep bundled themes first in their existing order and append imported themes alphabetically within each brightness group.
  Rationale: Preserves the current menu order users already know while keeping imported themes discoverable.
- Decision: Place the store in `LabanCore` rather than `LabanApp`.
  Rationale: The store is pure file I/O and JSON validation with no AppKit dependency; `LabanCoreTests` can test it directly.

## Surprises & Discoveries

- The `TerminalThemeStore` was initially marked `@MainActor` to mirror `TerminalBackgroundImageStore`, but that forced `ThemeMenuController` and `AppDelegate` wiring onto the main actor and broke the existing nonisolated `AppDelegate` lazy property pattern. Removing `@MainActor` from the theme store resolved the issue because the store has no UI or CoreGraphics dependencies.
- `Localizable.xcstrings` is generated by `scripts/gen-localizable-xcstrings.py` from a hardcoded translation table; new strings must be added to that table, then the generator run.
- The full repository gate fails on `LabanRendererTests.VectorSmoothScrollTests.testGlyphCentroidShiftsSubPixelAcrossHorizontalPhases` with non-monotonic centroid values. This reproduces in isolation and is unrelated to the theme-import changes; the only LabanRenderer edit is a public initializer in `Theme.swift`.

## Idempotence and Recovery

The format script and test commands are safe to rerun. Importing the same file twice fails with a collision error until the first theme is removed. Removing a theme that is currently selected causes the next menu/popup refresh to fall back to a bundled theme.
